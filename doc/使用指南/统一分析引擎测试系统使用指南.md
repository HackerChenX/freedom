# 统一分析引擎测试系统使用指南

## 概述

统一分析引擎测试系统是一个全面的测试框架，用于验证88个技术指标和复杂选股条件的正确性。系统连接真实的ClickHouse数据库，支持早停机制，能够快速发现并定位问题。

## 系统特性

### 🎯 核心功能
- **88个指标全覆盖**：包括基础指标、增强指标、ZXM指标、复合指标等
- **真实数据测试**：连接ClickHouse数据库，使用真实股票数据
- **早停机制**：发现错误立即停止，提高测试效率
- **多层次验证**：指标计算、逻辑验证、选股条件测试
- **智能报告**：生成详细的测试报告和修复建议

### ⚡ 性能优化
- **并发测试**：支持多线程并行测试
- **批量数据处理**：优化数据库查询性能
- **智能缓存**：避免重复计算
- **资源监控**：实时监控内存和CPU使用

## 快速开始

### 1. 启动交互式测试

```bash
# 进入项目根目录
cd /path/to/freedom

# 启动交互式测试界面
python scripts/start_unified_engine_test.py
```

### 2. 选择测试类型

系统提供7种测试类型：

| 选项 | 测试类型 | 说明 | 预计时间 |
|------|----------|------|----------|
| 1 | 🔥 快速测试 | 测试核心指标，适合日常验证 | ~5分钟 |
| 2 | ⭐ 优先级测试 | 测试最重要的10个指标 | ~10分钟 |
| 3 | 🔍 逻辑验证测试 | 深度验证指标计算逻辑 | ~15分钟 |
| 4 | 🎯 ZXM指标测试 | 测试ZXM体系24个指标 | ~20分钟 |
| 5 | 🔧 增强指标测试 | 测试11个增强指标 | ~15分钟 |
| 6 | 📊 全面测试 | 测试所有88个指标 | ~60分钟 |
| 7 | 💡 自定义测试 | 自定义测试参数 | 可变 |

### 3. 查看测试结果

测试完成后，系统会：
- 显示实时测试进度
- 生成详细的测试报告
- 提供修复建议
- 保存结果到文件

## 命令行使用

### 基本命令

```bash

```

### 验证规则

#### 计算验证
- **非空结果**：指标计算必须返回有效数据
- **数值合理性**：指标值必须在合理范围内
- **数据长度**：结果长度应符合预期
- **日期对齐**：指标日期应与股票数据对齐

#### 逻辑验证
- **MA指标**：验证平滑性和合理范围
- **RSI指标**：验证0-100范围和分布合理性
- **MACD指标**：验证DIF、DEA、MACD关系
- **KDJ指标**：验证K、D、J值的合理性
- **BOLL指标**：验证上中下轨的顺序关系

## 错误诊断

### 常见问题

#### 1. 数据库连接失败
```
❌ ClickHouse数据库连接失败
```
**解决方案**：
- 检查数据库服务是否启动
- 验证连接配置
- 确认网络连通性

#### 2. 指标计算错误
```
❌ 指标计算失败: division by zero
```
**解决方案**：
- 检查指标计算公式
- 验证输入数据完整性
- 添加异常处理

#### 3. 内存不足
```
❌ 内存使用超过限制
```
**解决方案**：
- 减少测试股票数量
- 降低并发测试数
- 优化数据处理逻辑

#### 4. 选股条件错误
```
❌ 选股条件评估失败
```
**解决方案**：
- 检查条件语法
- 验证字段名称
- 确认逻辑关系

## 常见问题解答

### Q1: 测试需要多长时间？
**A**: 根据测试类型不同：
- 快速测试：约5分钟
- 优先级测试：约10分钟
- 全面测试：约60分钟

### Q2: 如何减少测试时间？
**A**: 可以通过以下方式：
- 减少测试股票数量
- 增加并发测试数
- 使用快速测试模式
- 只测试特定指标组

### Q3: 测试失败后如何修复？
**A**: 根据测试报告：
1. 查看失败原因
2. 检查相关代码
3. 修复问题
4. 重新运行测试

### Q4: 如何添加自定义指标？
**A**: 需要：
1. 在指标注册表中注册
2. 实现计算逻辑
3. 添加测试策略
4. 添加验证规则

### Q5: 系统支持哪些数据库？
**A**: 目前主要支持ClickHouse，可以扩展支持其他数据库。
