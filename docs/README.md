## 🎯 命名规范

### 指标名称
- ✅ 使用大写英文字母和下划线：`MACD`, `RSI`, `BOLLINGER_BANDS`
- ❌ 避免小写或连字符：`macd`, `bollinger-bands`

### 形态和信号名称
- ✅ 使用清晰的中文技术术语：`MACD_金叉`, `RSI_超买`, `BOLL_上轨突破`
- ❌ 避免模糊词汇：`技术形态`, `未知形态`, `一般信号`

### 推荐词汇
- 趋势类：`上升趋势`, `下降趋势`, `横盘整理`
- 交叉类：`金叉`, `死叉`, `突破`, `跌破`
- 区域类：`超买`, `超卖`, `中性区域`
- 形态类：`顶部形态`, `底部形态`, `整理形态`
