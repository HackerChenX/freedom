## 🐛 发现的主要问题类型

### 1. 架构设计问题
- **抽象方法缺失**：指标类缺少基类要求的抽象方法实现
- **接口不一致**：不同指标的接口命名和参数不统一
- **继承问题**：`__init__`方法调用`super()`时传递了不兼容的参数

### 2. 兼容性问题
- **方法缺失**：测试期望的方法在指标类中不存在
- **返回格式不一致**：有些指标返回dict，有些返回DataFrame
- **类别名缺失**：注册表期望的类名与实际类名不匹配

### 3. 测试代码问题
- **断言方法名错误**：使用了不存在的断言方法
- **期望值不匹配**：测试期望与实际实现不符
- **日志处理器问题**：测试基础设施配置不正确

### 4. 导入和依赖问题
- **循环导入**：某些模块之间存在循环依赖
- **缺失导入**：测试文件缺少必要的导入语句
- **版本兼容性**：某些API在不同版本间不兼容

## 🔍 常见问题排查

### 问题1：导入错误
**症状**：`ImportError` 或 `ModuleNotFoundError`
**解决方案**：
- 检查import语句是否正确
- 确认文件路径和模块名
- 检查是否有循环导入

### 问题2：方法不存在
**症状**：`AttributeError: 'ClassName' object has no attribute 'method_name'`
**解决方案**：
- 检查方法名拼写
- 确认方法已在类中定义
- 参考已修复指标的实现

### 问题3：返回格式错误
**症状**：测试期望DataFrame但得到dict
**解决方案**：
- 统一返回DataFrame格式
- 检查计算方法的返回值
- 确保列名符合期望

### 问题4：测试断言失败
**症状**：`AssertionError` 或断言方法不存在
**解决方案**：
- 修复断言方法名（assert_xxx → assertXxx）
- 更新期望值以匹配实际实现
- 检查测试逻辑是否合理
