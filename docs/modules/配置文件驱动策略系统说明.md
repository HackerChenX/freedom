# 配置文件驱动的策略系统

## 🎯 系统概述

您的期望完全正确！策略不应该写在代码里，而应该通过配置文件自定义组合。我们已经构建了一个完整的配置文件驱动的策略系统，让您可以：

- ✅ **完全通过配置文件定义策略**，无需编程
- ✅ **灵活组合多个策略**，支持多种组合方式
- ✅ **动态调整参数**，实时生效
- ✅ **进行A/B测试**和参数优化
- ✅ **快速部署新策略**，无需重启系统

## 📁 系统架构

### 核心组件

1. **ConfigurableStrategyEngine** - 可配置策略引擎
2. **DynamicStrategy** - 动态策略类
3. **CombinationStrategy** - 组合策略类
4. **配置文件系统** - YAML/JSON配置文件

### 文件结构

```

```

## 📝 配置文件示例

### 单个策略配置

```yaml
# my_custom_momentum_strategy.yaml
strategy:
  id: "my_custom_momentum_strategy"
  name: "我的自定义动量策略"
  description: "结合KDJ、RSI、MACD的自定义动量策略"
  version: "1.0"
  category: "momentum"

technical_indicators:
  primary_indicators:
    - indicator_id: "KDJ"
      parameters:
        k_period: 9
        d_period: 3
        j_multiplier: 3
      conditions:
        - field: "k_value"
          operator: ">"
          value: "d_value"
          weight: 0.4
        - field: "k_value"
          operator: ">"
          value: 20
          weight: 0.3
      weight: 0.4
    
    - indicator_id: "RSI"
      parameters:
        period: 14
      conditions:
        - field: "rsi_value"
          operator: "<"
          value: 35
          weight: 0.6
      weight: 0.35
    
    - indicator_id: "MACD"
      parameters:
        fast_period: 12
        slow_period: 26
        signal_period: 9
      conditions:
        - field: "macd_histogram"
          operator: ">"
          value: 0
          weight: 1.0
      weight: 0.25

selection_parameters:
  max_selections: 25
  min_score: 0.65
  ranking_method: "composite_score"

filters:
  market_filters:
    markets: ["主板", "创业板", "科创板"]
    exclude_st: true
  financial_filters:
    market_cap:
      min: 10
      max: 1000
    price_range:
      min: 3.0
      max: 100.0
```

## 🚀 使用方法

### 1. 初始化策略引擎

```python
from strategy.configurable_strategy_engine import ConfigurableStrategyEngine

# 初始化引擎，指定配置文件目录
engine = ConfigurableStrategyEngine('config/strategies')
```

### 2. 查看可用策略

```python
# 获取所有可用策略
strategies = engine.get_available_strategies()
print(f"可用策略: {len(strategies)} 个")

# 获取策略组合
combinations = engine.get_strategy_combinations()
print(f"可用组合: {len(combinations)} 个")
```

### 3. 执行单个策略

```python
stock_codes = ['000001', '600519', '603359', '300003']
target_date = '2025-05-12'

# 执行自定义策略
results = engine.execute_strategy(
    'my_custom_momentum_strategy', 
    stock_codes, 
    target_date
)

print(f"策略选中: {len(results)} 只股票")
for stock in results:
    print(f"  {stock['stock_code']}: 评分 {stock['score']:.4f}")
```

### 4. 执行策略组合

```python
# 执行策略组合
combo_results = engine.execute_combination(
    'my_balanced_portfolio',
    stock_codes,
    target_date
)

print(f"组合选中: {len(combo_results)} 只股票")
```

### 5. 动态重载配置

```python
# 修改配置文件后，重新加载
engine.reload_strategies()
print("配置已重新加载，无需重启系统")
```

## ⚙️ 参数调优

### 通过配置文件调优

1. **修改技术指标参数**
```yaml
# 调整KDJ参数
parameters:
  k_period: 14  # 从9改为14，更平滑
  d_period: 5   # 从3改为5，更稳定
```

2. **调整选股条件**
```yaml
# 调整评分阈值
selection_parameters:
  min_score: 0.75  # 从0.65提高到0.75，更严格
  max_selections: 15  # 从25减少到15，更精选
```

3. **调整权重分配**
```yaml
# 调整指标权重
technical_indicators:
  primary_indicators:
    - indicator_id: "KDJ"
      weight: 0.5  # 增加KDJ权重
    - indicator_id: "RSI"
      weight: 0.3  # 减少RSI权重
    - indicator_id: "MACD"
      weight: 0.2  # 减少MACD权重
```

## 🧪 A/B测试

### 创建测试版本

```yaml
# 策略A: 保守版本
kdj_conservative_strategy:
  name: "KDJ保守策略"
  technical_indicators:
    primary_indicators:
      - indicator_id: "KDJ"
        parameters:
          k_period: 14
        conditions:
          - field: "k_value"
            operator: ">"
            value: 30  # 更高的阈值
  selection_parameters:
    min_score: 0.75  # 更严格的评分

# 策略B: 激进版本  
kdj_aggressive_strategy:
  name: "KDJ激进策略"
  technical_indicators:
    primary_indicators:
      - indicator_id: "KDJ"
        parameters:
          k_period: 5
        conditions:
          - field: "k_value"
            operator: ">"
            value: 15  # 更低的阈值
  selection_parameters:
    min_score: 0.55  # 更宽松的评分
```

### 并行测试

```python
# 同时测试两个版本
results_a = engine.execute_strategy('kdj_conservative_strategy', stocks, date)
results_b = engine.execute_strategy('kdj_aggressive_strategy', stocks, date)

# 比较结果
print(f"保守策略选中: {len(results_a)} 只")
print(f"激进策略选中: {len(results_b)} 只")
```

## 🔗 策略组合方式

### 1. 并集 (Union)
```yaml
combination_method: "union"
# 选择所有策略选中的股票，去重后合并
```

### 2. 交集 (Intersection)
```yaml
combination_method: "intersection"  
# 只选择所有策略都选中的股票
```

### 3. 加权平均 (Weighted Average)
```yaml
combination_method: "weighted_average"
# 根据权重计算综合评分，按评分排序
```
