## 🎯 各模块核心定位

### 1. 技术指标分析模块 📊
**定位**: 技术分析基础设施
**核心价值**: 为选股提供标准化的技术条件和形态识别
**服务对象**: 策略选股、买点回测、市场监控

**关键功能**:
- ✅ **103个技术指标**: 已验证的标准化计算
- ✅ **6个时间周期**: 15分钟到月线的全覆盖
- ✅ **形态识别**: 基于已验证形态的标准化识别
- ✅ **信号生成**: 买卖信号的标准化生成

### 2. 策略选股分析模块 🎯 **[核心模块]**
**定位**: 生产级选股执行引擎
**核心价值**: 将技术分析转化为实际可执行的选股决策
**服务对象**: 投资决策、量化交易、风险管理

**关键功能**:
- 🔧 **通达信风格公式**: 灵活的策略配置语法
- ⚡ **高性能执行**: 全市场5000+股票 < 2分钟
- 📈 **绩效跟踪**: 实时策略绩效监控和优化
- 🔌 **API集成**: 完整的RESTful API接口

### 3. 买点回测分析模块 📈
**定位**: 历史买点深度分析工具
**核心价值**: 为选股策略提供历史验证和数据支撑
**服务对象**: 策略选股、投资研究、策略开发

**关键功能**:
- 📥 **买点数据管理**: 多格式买点数据导入和验证
- 🔍 **多周期分析**: 买点的全面技术特征分析
- 📊 **形态统计**: 成功买点的形态频率和有效性统计
- 🎯 **策略提取**: 从历史数据中自动提取有效策略

### 4. 市场监控模块 🔔
**定位**: 选股执行的实时数据支撑和智能预警
**核心价值**: 为选股决策提供实时市场状态和风险预警
**服务对象**: 策略选股、投资决策、风险管理、交易执行

**关键功能**:
- 📡 **实时数据监控**: 3秒内更新的实时行情和指标
- 🚨 **智能预警系统**: 基于技术形态的多级预警
- 📈 **趋势跟踪**: 多周期趋势状态的实时跟踪
- 🛡️ **风险监控**: 投资组合和市场系统性风险监控

## 📊 模块间协同关系

### 数据流向图
```
技术指标分析模块 ──→ 策略选股分析模块 ←── 买点回测分析模块
       ↓                    ↓                    ↑
       └─────────→ 市场监控模块 ←─────────────────┘

数据流说明:
• 技术指标 → 选股: 提供技术条件和形态识别
• 买点回测 → 选股: 提供历史验证的策略规则  
• 监控 → 选股: 提供实时数据支撑和市场状态
• 选股 → 监控: 提供需要监控的股票和策略
```

### 功能协同矩阵
| 协同关系 | 技术指标模块 | 策略选股模块 | 买点回测模块 | 市场监控模块 |
|---------|-------------|-------------|-------------|-------------|
| **技术指标模块** | - | 提供技术条件 | 提供指标计算 | 提供指标基础 |
| **策略选股模块** | 使用技术条件 | - | 使用历史策略 | 使用实时数据 |
| **买点回测模块** | 使用指标计算 | 提供策略验证 | - | 使用历史监控 |
| **市场监控模块** | 使用指标基础 | 监控选股结果 | 提供历史数据 | - |
