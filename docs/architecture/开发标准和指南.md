## 🏗️ 架构设计原则

### 1. SOLID原则

#### 1.1 单一职责原则 (SRP)
- 每个类只负责一个功能
- 修改原因只有一个

```python
# 好的例子
class StockDataLoader:
    """只负责加载股票数据"""
    def load_from_database(self, code: str) -> pd.DataFrame:
        pass

class IndicatorCalculator:
    """只负责计算指标"""
    def calculate_ma(self, data: pd.DataFrame, period: int) -> pd.Series:
        pass

# 不好的例子
class StockAnalyzer:
    """职责过多，违反SRP"""
    def load_data(self, code: str) -> pd.DataFrame:
        pass
    def calculate_indicators(self, data: pd.DataFrame) -> Dict:
        pass
    def save_results(self, results: Dict) -> None:
        pass
```

#### 1.2 开放封闭原则 (OCP)
- 对扩展开放，对修改封闭
- 使用抽象和多态

```python
from abc import ABC, abstractmethod

class BaseIndicator(ABC):
    """指标基类"""
    
    @abstractmethod
    def calculate(self, data: pd.DataFrame) -> pd.Series:
        """计算指标值"""
        pass

class MAIndicator(BaseIndicator):
    """移动平均线指标"""
    
    def __init__(self, period: int):
        self.period = period
        
    def calculate(self, data: pd.DataFrame) -> pd.Series:
        return data['close'].rolling(self.period).mean()
```
