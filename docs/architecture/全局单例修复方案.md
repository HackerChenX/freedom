**修复原则**:
1. 向后兼容：保持现有API接口不变
2. 渐进式迁移：分批次逐步替换
3. 测试驱动：确保修复后功能正常
4. 性能优化：减少全局状态依赖

### 1. 依赖注入容器增强

#### 当前容器问题分析

# 1. 命名不规范（get_service_Optimize_Global_Singletons_Optimize_Global_Singletons）
# 2. 缺乏生命周期管理
# 3. 没有循环依赖检测

#### 优化后的容器实现
```python
class ServiceContainer:
    """优化后的依赖注入容器"""
    
    def __init__(self):
        self._services: Dict[Type, ServiceDescriptor] = {}
        self._instances: Dict[Type, Any] = {}
        self._building: Set[Type] = set()  # 循环依赖检测
        self._lock = threading.RLock()
    
    def register_singleton(self, interface: Type[T], 
                          implementation: Type[T] = None,
                          factory: Callable[[], T] = None) -> 'ServiceContainer':
        """注册单例服务"""
        with self._lock:
            if factory:
                descriptor = ServiceDescriptor(
                    interface=interface,
                    factory=factory,
                    lifetime=ServiceLifetime.SINGLETON
                )
            else:
                implementation = implementation or interface
                descriptor = ServiceDescriptor(
                    interface=interface,
                    implementation=implementation,
                    lifetime=ServiceLifetime.SINGLETON
                )
            
            self._services[interface] = descriptor
            return self
    
    def resolve(self, interface: Type[T]) -> T:
        """解析服务实例"""
        with self._lock:
            # 循环依赖检测
            if interface in self._building:
                raise CircularDependencyError(f"Circular dependency detected: {interface}")
            
            # 检查是否已有实例
            if interface in self._instances:
                return self._instances[interface]
            
            # 检查是否已注册
            if interface not in self._services:
                raise ServiceNotRegisteredError(f"Service not registered: {interface}")
            
            descriptor = self._services[interface]
            
            # 开始构建
            self._building.add(interface)
            try:
                if descriptor.factory:
                    instance = descriptor.factory()
                else:
                    instance = descriptor.implementation()
                
                # 如果是单例，缓存实例
                if descriptor.lifetime == ServiceLifetime.SINGLETON:
                    self._instances[interface] = instance
                
                return instance
            finally:
                self._building.discard(interface)
```

_legacy_instance = None

def get_memory_cache() -> MemoryCache:
    """获取内存缓存实例（向后兼容）"""
    global _legacy_instance
    if _legacy_instance is None:
        with _legacy_lock:
            if _legacy_instance is None:
                # 从容器获取实例
                container = get_container()
                if container.is_registered(MemoryCache):
                    _legacy_instance = container.resolve(MemoryCache)
                else:

### 4. 迁移辅助工具

#### 自动化迁移脚本
```python
class SingletonMigrationTool:
    """单例迁移工具"""
    
    def __init__(self):
        self.migration_map = {
            'get_memory_cache()': 'get_service(MemoryCache)',
            'PeriodManager.get_instance()': 'get_service(PeriodManager)',
            'PatternRegistry.get_instance()': 'get_service(PatternRegistry)',
            # ... 其他映射
        }
    
    def migrate_file(self, file_path: str) -> bool:
        """迁移单个文件"""
        try:
            with open(file_path, 'r', encoding='utf-8') as f:
                content = f.read()
            
            # 添加导入
            if 'from utils.dependency_injection import get_service' not in content:
                content = self._add_import(content)
            
            # 替换调用
            for old_call, new_call in self.migration_map.items():
                content = content.replace(old_call, new_call)
            
            with open(file_path, 'w', encoding='utf-8') as f:
                f.write(content)
            
            return True
        except Exception as e:
            logger.error(f"迁移文件 {file_path} 失败: {e}")
            return False
    
    def _add_import(self, content: str) -> str:
        """添加依赖注入导入"""
        lines = content.split('\n')
        import_end = 0
        
        for i, line in enumerate(lines):
            if line.strip().startswith('from ') or line.strip().startswith('import '):
                import_end = i + 1
        
        lines.insert(import_end, 'from utils.dependency_injection import get_service')
        return '\n'.join(lines)
```

## 🚨 风险控制

### 主要风险点
1. **向后兼容性**：现有代码调用可能中断
2. **性能影响**：依赖注入可能带来性能开销
3. **测试覆盖**：单例重构可能影响测试
4. **并发安全**：多线程环境下的安全性

### 缓解措施
1. **分阶段迁移**：保持向后兼容接口
2. **性能监控**：对比迁移前后性能
3. **充分测试**：补充单元测试和集成测试
4. **线程安全**：使用线程安全的容器实现

### 回滚计划
1. **版本控制**：每个阶段创建Git标签
2. **配置开关**：支持切换到旧实现
3. **监控告警**：实时监控系统状态
4. **快速回滚**：准备快速回滚脚本
