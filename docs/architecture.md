# 股票分析系统架构文档

## 🏗️ 系统架构概述

本系统采用六层架构设计，实现了高内聚低耦合的技术指标分析系统。

### 架构分层

```
L6: 用户接口层 (bin/, api/)
    ↓ 只能调用 L5
L5: 业务应用层 (strategy/, analysis/)
    ↓ 只能调用 L4
L4: 核心服务层 (indicators/, formula/)
    ↓ 只能调用 L3
L3: 数据服务层 (db/interfaces/, db/managers/)
    ↓ 只能调用 L2
L2: 存储访问层 (db/enhanced_connection_pool.py)
    ↓ 只能调用 L1
L1: 基础设施层 (utils/, config/, enums/)
```

## 📊 核心组件

### 1. 指标注册系统
- **文件**: `indicators/complete_indicator_registry.py`
- **功能**: 统一管理128个技术指标的注册和创建
- **特点**: 100%注册成功率，支持动态加载

### 2. 指标基类系统
- **文件**: `indicators/base_indicator.py`
- **功能**: 提供统一的指标接口和抽象方法
- **特点**: 强制实现标准化方法，确保一致性

### 3. 数据库连接池
- **文件**: `db/enhanced_connection_pool.py`
- **功能**: 高效的ClickHouse数据库连接管理
- **特点**: 支持5-20并发连接，自动重试机制

### 4. 依赖注入容器
- **文件**: `utils/dependency_injection.py`
- **功能**: 管理服务依赖关系，实现松耦合
- **特点**: 自动解析依赖，支持单例模式

## 🎯 指标分类体系

### 核心技术指标 (6个)
- MA, EMA, MACD, RSI, BOLL, KDJ

### 趋势指标 (12个)
- DMA, DMI, ADX, AROON, SAR, TRIX, CCI, ENHANCED_CCI, ENHANCED_TRIX, WMA, PSAR, SUPERTREND

### 振荡器指标 (13个)
- KDJ, WR, WILLIAMS_R, CMO, STOCHRSI, STOCH, ENHANCED_RSI, ENHANCED_KDJ, ENHANCED_WR, MOMENTUM, ROC, ROC_OSCILLATOR, ULTIMATE

### 成交量指标 (10个)
- OBV, AD, EMV, VOL, VR, VOSC, MFI, PVT, CHAIKIN, FORCE_INDEX

### 波动性指标 (7个)
- ATR, KC, VIX, STDDEV, VOLATILITY, CHAIKIN_VOLATILITY, GARMAN_KLASS

### ZXM体系指标 (38个)
- 包含资金流向、筹码分布、机构行为等专业分析指标

### 形态识别指标 (23个)
- 蜡烛图形态、反转形态、持续形态等

### 增强指标 (3个)
- ENHANCED_MACD, ENHANCED_BOLL, ENHANCED_STOCHRSI

### 其他专业指标 (16个)
- 包含综合评分、协同分析等高级指标
