**风险价值计算**
```python
def calculate_var(self, returns, confidence_level=0.95):
    # 历史模拟法VaR计算
    sorted_returns = returns.sort_values()
    var_index = int((1 - confidence_level) * len(sorted_returns))
    return abs(sorted_returns.iloc[var_index])
```
