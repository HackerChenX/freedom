# 买点回测系统完整实现文档

## 📋 项目概述

本文档记录了基于用户设想的完整买点回测工作流程的系统实现。该系统完美实现了从买点输入到策略生成和双向验证的全自动化流程。

## 🎯 用户原始设想

> "我设想的工作流程，我提供多个个股和对应的买点日期。格式如同buypoints.csv所示。买点回测脚本首先从clickhouse中逐个查询出个股的信息，起始时间是数据库中此个股的最小时间，截止时间是我输入的买点日期。需要分别查询出 15 分钟、30 分钟、60分钟、日线、周线、月线（其中 30 分钟和60 分钟的数据在数据库中不存在，需要根据 15 分钟数据计算出来）。然后根据股票数据，逐个测试系统中的指标，判断买点当日，分别5 分钟、30 分钟、60 分钟、日线、周线、月线周期下，在是否命中了哪些指标的技术形态。每个周期下命中的技术指标都是独立的，即便不同周期下命中相同的指标，也不能把他们看成一样的，比如日线 KDJ金叉和月线 KDJ金叉是两个不同的形态。计算出每个个股在买点当日命中的技术形态，并结合指标打分机制。然后根据命中的技术形态，转换为选股策略，然后根据选股策略，能够从clickhouse中选出符合策略的股票，同时也可以进行双向验证"

### 3. 关键技术实现

#### 3.1 指标与周期强制绑定机制 ⚠️ **核心原则**

**关键设计原则**: 指标分析永远不能脱离周期，指标和周期必须绑定在一起计算和统计。

```python
# 强制绑定：指标 + 周期 = 唯一技术形态
unique_id = f"{indicator_name}_{period}_{pattern_name}"

# 严格区分示例:
# "MACD_daily_golden_cross"    - 日线MACD金叉
# "MACD_30min_golden_cross"    - 30分钟MACD金叉
# "MACD_weekly_golden_cross"   - 周线MACD金叉

# ❌ 绝对禁止的模式
# "MACD_golden_cross"          - 缺少周期信息
# "golden_cross"               - 缺少指标和周期信息
```

**统计和分析规则**:
- 所有统计必须按照"指标+周期"组合进行
- 热门排行显示"30分钟MACD"、"日线MACD"等
- 不同周期下的相同指标被视为完全不同的技术形态
- 策略生成时必须明确指定周期条件
