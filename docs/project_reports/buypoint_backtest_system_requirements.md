# 买点回测系统需求文档

## 📋 项目概述

### 系统目标
构建一个基于历史买点的技术分析回测系统，通过分析历史成功买点的技术形态特征，自动生成选股策略并进行双向验证，为量化交易提供技术支撑。

### 核心价值
- **历史经验挖掘**: 从历史成功买点中提取有效的技术形态组合
- **策略自动生成**: 基于形态分析结果自动构建选股策略
- **双向验证机制**: 确保生成策略的实际有效性
- **多周期分析**: 支持从分钟级到月线的全周期技术分析

## 🎯 业务需求

### 1. 核心业务流程
```
输入买点数据 → 多周期技术分析 → 形态识别统计 → 策略生成 → 选股验证 → 结果输出
```

### 2. 用户角色定义
- **量化分析师**: 使用系统进行买点分析和策略研究
- **投资决策者**: 基于系统输出进行投资决策
- **系统管理员**: 维护系统运行和数据质量

### 3. 业务场景
- **历史买点复盘**: 分析历史成功买点的技术特征
- **策略研发**: 基于历史数据生成新的选股策略
- **策略验证**: 验证策略在当前市场的有效性
- **形态研究**: 研究不同周期下技术形态的有效性

### 核心功能模块

#### 1. 数据管理模块
**功能职责**: 管理系统所需的各类数据
- **买点数据管理**: 加载、验证、解析买点文件
- **股票数据获取**: 多周期K线数据查询和缓存
- **数据质量控制**: 数据完整性检查和异常处理
- **数据转换服务**: 周期数据转换（15分钟→30分钟、60分钟）

#### 2. 买点分析模块 🎯
**功能职责**: 对历史买点进行全面的技术分析

##### 2.1 多周期数据处理
- **支持周期**: 15分钟、30分钟、60分钟、日线、周线、月线
- **数据获取**: 从买点日期向前获取足够的历史数据
- **周期转换**: 自动将15分钟数据合并为30分钟、60分钟数据
- **数据同步**: 确保不同周期数据的时间对齐

##### 2.2 技术指标计算
- **指标覆盖**: 支持103个已验证的技术指标
- **分类计算**: 
  - 基础指标（MA、MACD、RSI、KDJ等）
  - ZXM体系指标（专业买点指标）
  - 形态识别指标（K线形态、价格形态）
  - 评分指标（综合评分体系）
- **周期独立**: 每个周期独立计算，确保指标与周期强制绑定

##### 2.3 买点形态识别
- **形态提取**: 识别买点当日命中的技术形态
- **周期标识**: 为每个形态生成唯一标识（指标_周期_形态）
- **强度评估**: 计算形态的强度和可靠性
- **时间定位**: 精确定位买点在数据中的位置

##### 2.4 买点评分机制
- **多维评分**: 从多个维度对买点质量进行评分
- **周期权重**: 不同周期赋予不同权重
- **指标权重**: 根据指标重要性分配权重
- **综合评分**: 生成买点的综合质量评分

#### 3. 指标形态模块 📊
**功能职责**: 管理和识别各类技术指标形态

##### 3.1 指标注册管理
- **指标注册表**: 维护103个指标的注册信息
- **动态加载**: 支持指标的动态加载和实例化
- **版本管理**: 管理指标的版本和更新
- **质量监控**: 监控指标计算的成功率和质量

##### 3.2 形态识别引擎
- **形态定义**: 标准化的形态识别规则
- **模式匹配**: 高效的形态模式匹配算法
- **参数配置**: 可配置的形态识别参数
- **结果标准化**: 统一的形态识别结果格式

##### 3.3 形态统计分析
- **频率统计**: 统计各形态在成功买点中的出现频率
- **有效性分析**: 分析形态的预测有效性
- **组合分析**: 分析形态组合的协同效应
- **周期对比**: 对比不同周期下形态的表现

##### 3.4 形态评分体系
- **单一形态评分**: 对单个形态进行评分
- **组合形态评分**: 对形态组合进行综合评分
- **动态权重**: 根据历史表现动态调整权重
- **置信度计算**: 计算形态识别的置信度

#### 4. 策略选股模块 🎯
**功能职责**: 基于买点分析结果生成和执行选股策略

##### 4.1 策略生成引擎
- **形态组合分析**: 识别最有效的形态组合
- **策略模板**: 基于模板生成标准化策略
- **条件构建**: 将形态组合转换为可执行的选股条件
- **参数优化**: 自动优化策略参数

##### 4.2 选股执行引擎
- **股票池管理**: 管理可选股票池
- **条件匹配**: 将策略条件与实时数据匹配
- **多周期验证**: 在多个周期上验证选股条件
- **评分排序**: 对符合条件的股票进行评分排序

##### 4.3 策略验证机制
- **双向验证**: 策略生成后立即进行选股验证
- **历史回测**: 在历史数据上验证策略有效性
- **实时验证**: 在当前市场数据上验证策略
- **成功率统计**: 统计策略的成功率和准确性

##### 4.4 策略优化服务
- **参数调优**: 自动调整策略参数以提高效果
- **条件精化**: 精化选股条件以提高精确度
- **组合优化**: 优化形态组合以提高成功率
- **动态更新**: 根据市场变化动态更新策略

## 🎯 关键设计原则

### 1. 指标与周期强制绑定原则 ⚠️
- **原则**: 指标分析永远不能脱离周期
- **实现**: 所有指标必须与具体周期绑定
- **标识**: 使用"指标_周期_形态"格式的唯一标识
- **统计**: 所有统计分析按"指标+周期"组合进行

### 2. 数据驱动决策原则
- **原则**: 所有策略生成基于历史数据分析
- **实现**: 通过统计学方法识别有效形态组合
- **验证**: 生成的策略必须通过双向验证
- **优化**: 基于验证结果持续优化策略

### 3. 系统可扩展性原则
- **原则**: 系统设计支持功能扩展和性能扩展
- **实现**: 模块化设计，标准化接口
- **扩展**: 支持新指标、新周期、新策略类型
- **性能**: 支持并行处理和分布式部署

### 4. 结果可追溯性原则
- **原则**: 所有分析结果可追溯到原始数据
- **实现**: 完整的数据链路和计算过程记录
- **审计**: 支持结果审计和问题排查
- **透明**: 分析过程和决策逻辑透明可见
