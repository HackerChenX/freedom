# 指标调试验证使用指南

## 概述

指标调试验证器是专门为调试和测试指标有效性而设计的工具，支持早停功能，能够在选出符合条件的个股或遇到报错时立即停止执行，便于快速定位和修复问题。

## 核心功能

### 1. 早停功能 🛑
- **成功后停止**: 当任何一个指标成功选出股票时立即停止
- **错误后停止**: 当任何一个指标验证出错时立即停止
- **调试模式**: 提供详细的调试信息输出

### 2. 验证模式
- **QUICK**: 快速验证核心指标（MA、MACD、RSI等）
- **PRIORITY**: 按重要性优先级验证
- **CATEGORY**: 按指标类型分类验证
- **FULL**: 验证所有88个已注册指标

### 3. 灵活配置
- 可调整股票池大小
- 可设置选股比例阈值
- 支持单线程或多线程验证
- 支持多种输出格式

## 配置说明

### IndicatorValidationConfig 参数

```python
@dataclass
class IndicatorValidationConfig:
    mode: ValidationMode = ValidationMode.FULL           # 验证模式
    stock_pool_size: int = 1000                         # 股票池大小
    max_selection_ratio: float = 0.1                    # 最大选股比例
    min_selection_count: int = 1                        # 最小选股数量
    validation_date: str = None                         # 验证日期
    timeout_seconds: int = 300                          # 超时时间（秒）
    parallel_workers: int = 4                           # 并行工作线程数
    output_format: str = "json"                         # 输出格式
    save_details: bool = True                           # 是否保存详细结果
    stop_on_success: bool = False                       # 🔑 成功选股后立即停止
    stop_on_error: bool = False                         # 🔑 遇到错误后立即停止
    debug_mode: bool = False                            # 🔑 调试模式：打印详细信息
```

### 调试配置的默认值

```python
def create_debug_config():
    return IndicatorValidationConfig(
        mode=ValidationMode.QUICK,        # 快速模式，只验证核心指标
        stock_pool_size=100,              # 较小的股票池，加快验证速度
        max_selection_ratio=0.2,          # 较宽松的选股比例限制
        min_selection_count=1,            # 最少选出1只股票就算成功
        parallel_workers=1,               # 单线程，确保顺序执行
        stop_on_success=True,             # 🔑 成功后立即停止
        stop_on_error=True,               # 🔑 错误后立即停止
        debug_mode=True,                  # 🔑 开启调试模式
        save_details=True,                # 保存详细结果
        output_format="json"              # JSON格式输出
    )
```

## 验证结果状态

### 成功状态
- **SUCCESS**: 成功验证，选股数量在合理范围内
- 显示选中的股票代码
- 显示选股数量和比例

### 失败状态
- **NO_SELECTION**: 未选出任何股票
- **OVER_SELECTION**: 选股过多（超过最大选股比例）
- **ERROR**: 验证过程出现错误
- **TIMEOUT**: 验证超时

## 早停功能详解

### 1. 成功后早停 (stop_on_success=True)

**触发条件**: 任何指标验证成功（选出≥1只股票）

**应用场景**:
- 快速验证系统是否正常工作
- 寻找第一个有效的指标
- 调试指标计算逻辑

**日志输出**:
```
✅ 指标 MA 验证成功: 选出 15 只股票
选中股票: ['000001', '000002', '600000', '600036', '000858']
🛑 配置了成功后早停，在指标 MA 成功后停止验证
已验证 1/12 个指标，其中成功 1 个
```

### 2. 错误后早停 (stop_on_error=True)

**触发条件**: 任何指标验证出错

**应用场景**:
- 快速定位系统错误
- 调试指标计算异常
- 修复配置问题

**日志输出**:
```
❌ 指标 MACD 验证出错: 计算MACD时出现除零错误
🛑 配置了错误后早停，在指标 MACD 出错后停止验证
已验证 2/12 个指标，其中失败 1 个
```

### 3. 调试模式 (debug_mode=True)

**功能**: 提供详细的调试信息

**输出内容**:
- 选中股票的具体代码
- 选股数量和比例的详细信息
- 策略配置的详细内容
- 执行时间统计

## 故障排除

### 常见问题

1. **指标未注册**
   - 错误：`KeyError: 'UNKNOWN_INDICATOR'`
   - 解决：检查指标是否在complete_registry中注册

2. **数据库连接失败**
   - 错误：`Connection refused`
   - 解决：确认ClickHouse数据库正在运行

3. **策略生成失败**
   - 错误：`策略生成失败`
   - 解决：检查指标的条件生成逻辑

4. **选股数量异常**
   - 现象：选股数量为0或过多
   - 解决：调整max_selection_ratio和min_selection_count参数

### 调试技巧

1. **使用单个指标调试**
   ```bash
   python scripts/indicator_debug_validator.py --indicator PROBLEMATIC_INDICATOR
   ```

2. **启用详细日志**
   ```python
   import logging
   logging.getLogger().setLevel(logging.DEBUG)
   ```

3. **检查策略配置**
   - 查看生成的策略配置是否正确
   - 验证条件逻辑是否合理

4. **分步骤验证**
   - 先验证指标计算
   - 再验证条件评估
   - 最后验证策略执行

4. **问题排查**: 结合单个指标调试和批量验证

指标调试验证器是一个强大的调试工具，通过早停功能可以：
- 快速定位问题指标
- 及时发现系统异常
- 提高调试效率
- 减少不必要的计算资源消耗

合理使用早停功能，可以显著提升指标验证和问题排查的效率。
