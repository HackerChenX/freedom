## 算法技术细节

### 核心计算公式 ✅
1. **资金流乘数 (MFM)**:
   ```
   MFM = ((Close - Low) - (High - Close)) / (High - Low)
   ```

2. **资金流量 (MFV)**:
   ```
   MFV = MFM × Volume
   ```

3. **累积/派发线 (AD)**:
   ```
   AD = Σ(MFV) = 前期AD + 当期MFV
   ```

### 特殊处理机制 ✅
- **除零保护**: 当High=Low时，使用1e-10避免除零错误
- **无穷值处理**: 正确处理inf和-inf值
- **NaN值处理**: 正确处理计算初期的NaN值
- **累积计算**: 使用cumsum()进行高效累积计算
