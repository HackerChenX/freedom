## 算法技术细节

### 核心计算公式 ✅
1. **枢轴点计算**:
   ```
   PP = (前日高点 + 前日低点 + 前日收盘) / 3
   ```

2. **阻力位计算**:
   ```
   R1 = 2 × PP - 前日低点
   R2 = PP + (前日高点 - 前日低点)
   ```

3. **支撑位计算**:
   ```
   S1 = 2 × PP - 前日高点
   S2 = PP - (前日高点 - 前日低点)
   ```

4. **信号生成逻辑**:
   ```
   买入: 价格接近支撑位且反弹
   卖出: 价格接近阻力位且回落
   ```
