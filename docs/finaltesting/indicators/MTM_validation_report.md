## 算法技术细节

### 核心计算公式 ✅
1. **动量指标计算**:
   ```
   MTM = CLOSE - REF(CLOSE, N)
   其中：N为计算周期，默认为10
   ```

2. **动量移动平均**:
   ```
   MTMMA = MA(MTM, M)
   其中：M为平滑周期，默认为6
   ```

3. **动态阈值计算**:
   ```
   超买阈值 = 历史MTM的75%分位数
   超卖阈值 = 历史MTM的25%分位数
   ```

4. **信号生成逻辑**:
   ```
   买入: MTM > 0 & MTM > MTMMA & MTM上升
   卖出: MTM < 0 & MTM < MTMMA & MTM下降
   ```

### 特殊处理机制 ✅
- **NaN值处理**: 正确处理计算初期的NaN值
- **动态阈值**: 基于历史数据自动计算超买超卖阈值
- **信号过滤**: 通过移动平均减少虚假信号
- **精度保证**: 使用高精度浮点计算确保准确性
