## 算法技术细节

### 核心计算公式 ✅
1. **多周期RSI计算**:
   ```
   RSI_n = 100 - (100 / (1 + RS_n))
   其中 RS_n = 平均上涨幅度_n / 平均下跌幅度_n
   ```

2. **自适应阈值**:
   ```
   动态超买阈值 = 基础阈值 + 波动性调整
   动态超卖阈值 = 基础阈值 - 波动性调整
   ```

3. **背离检测**:
   ```
   背离信号 = 价格趋势方向 ≠ RSI趋势方向
   ```
