## 算法技术细节

### 核心计算公式 ✅
1. **价格变化分类**:
   ```
   Up_Days: Close > Close_prev
   Down_Days: Close < Close_prev
   Equal_Days: Close = Close_prev
   ```

2. **成交量分类**:
   ```
   Up_Volume: Volume on Up_Days
   Down_Volume: Volume on Down_Days
   Equal_Volume: Volume on Equal_Days
   ```

3. **VR计算**:
   ```
   VR = (Σ(Up_Volume) + Σ(Equal_Volume)/2) / (Σ(Down_Volume) + Σ(Equal_Volume)/2) × 100
   ```

4. **VR均线**:
   ```
   VR_MA = MA(VR, ma_period)
   ```

### 特殊处理机制 ✅
- **NaN值处理**: 正确处理计算初期的NaN值
- **滚动计算**: 使用pandas rolling()方法进行高效计算
- **成交量分类**: 使用where()方法进行条件分类
- **除零保护**: 避免分母为零的情况
