## 算法技术细节

### 核心计算公式 ✅
1. **随机RSI计算**:
   ```
   StochRSI = (RSI - RSI_min) / (RSI_max - RSI_min) × 100
   其中 RSI_min 和 RSI_max 是指定周期内的RSI最小值和最大值
   ```

2. **%K线平滑**:
   ```
   %K = MA(StochRSI, k_period)
   ```

3. **%D线平滑**:
   ```
   %D = MA(%K, d_period)
   ```

4. **自适应阈值**:
   ```
   动态超买阈值 = 基础阈值 + 波动性调整
   动态超卖阈值 = 基础阈值 - 波动性调整
   ```
