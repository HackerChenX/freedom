## 算法技术细节

### 核心计算公式 ✅
1. **第一重EMA**:
   ```
   EMA1 = EMA(Close, N)
   ```

2. **第二重EMA**:
   ```
   EMA2 = EMA(EMA1, N)
   ```

3. **第三重EMA（TR）**:
   ```
   TR = EMA(EMA2, N)
   ```

4. **TRIX计算**:
   ```
   TRIX = (TR - REF(TR, 1)) / REF(TR, 1) × 100
   ```

5. **MATRIX计算**:
   ```
   MATRIX = MA(TRIX, M)
   ```
