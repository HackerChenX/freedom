## 技术特点

### MTM指标优势
1. **动量量化**: 准确量化价格变化的动量强度
2. **趋势确认**: 帮助确认价格趋势的持续性
3. **超买超卖**: 识别市场的超买超卖状态
4. **零轴分析**: 通过零轴穿越判断趋势转换

### 计算方法
- **基础公式**: MTM = Close - Close[n]
- **周期参数**: 默认10期，可自定义
- **平滑处理**: 使用移动平均平滑MTM波动
- **阈值设定**: 自动计算超买超卖线

## 应用指南

### MTM信号解读
- **MTM > 0**: 价格上涨动量，看涨信号
- **MTM < 0**: 价格下跌动量，看跌信号
- **MTM接近0**: 价格变化缓慢，观望信号
- **MTM极值**: 可能出现反转，注意风险

### 交易策略
1. **零轴交叉**: MTM穿越零轴时的交易机会
2. **金叉死叉**: MTM与MTMMA交叉的信号
3. **超买超卖**: 在极值区域的反向交易
4. **背离分析**: 价格与MTM背离时的机会

### 风险控制
- **止损设置**: 当MTM反向突破时考虑止损
- **仓位管理**: 根据MTM强度调整仓位大小
- **时间过滤**: 避免在MTM极值时追涨杀跌
- **组合使用**: 与其他指标组合使用提高准确性
