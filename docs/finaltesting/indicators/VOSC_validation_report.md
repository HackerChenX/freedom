## 算法技术细节

### 核心计算公式 ✅
1. **成交量震荡计算**:
   ```
   VOSC = (短期成交量MA - 长期成交量MA) / 长期成交量MA × 100%
   ```

2. **成交量震荡信号**:
   ```
   VOSC_SIGNAL = MA(VOSC, signal_period)
   ```
