## 算法技术细节

### 核心计算公式 ✅
1. **DIF线计算**:
   ```
   DIF = EMA(Close, fast_period) - EMA(Close, slow_period)
   ```

2. **DEA线计算**:
   ```
   DEA = EMA(DIF, signal_period)
   ```

3. **柱状图计算**:
   ```
   HISTOGRAM = DIF - DEA
   ```

4. **动量分析**:
   ```
   MOMENTUM = (DIF - DIF_prev) / DIF_prev
   ```

5. **趋势强度**:
   ```
   TREND_STRENGTH = |HISTOGRAM| / (|DIF| + |DEA|)
   ```
