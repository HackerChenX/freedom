## 算法技术细节

### 核心计算公式 ✅
1. **RSI计算**:
   ```
   RSI = 100 - (100 / (1 + RS))
   其中 RS = 平均上涨幅度 / 平均下跌幅度
   ```

2. **随机RSI计算**:
   ```
   StochRSI = (RSI - RSI最低值) / (RSI最高值 - RSI最低值) × 100
   ```

3. **K值计算**:
   ```
   %K = StochRSI的K期移动平均
   ```

4. **D值计算**:
   ```
   %D = %K的D期移动平均
   ```
