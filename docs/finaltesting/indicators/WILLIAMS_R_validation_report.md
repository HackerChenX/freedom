## 算法技术细节

### 核心计算公式 ✅
1. **威廉指标计算**:
   ```
   WR = (HH - C) / (HH - LL) × (-100)
   其中：HH为N日内最高价，LL为N日内最低价，C为当日收盘价
   ```

2. **移动平均计算**:
   ```
   WR_MA_3 = MA(WR, 3)
   WR_MA_6 = MA(WR, 6)
   ```

3. **变化分析**:
   ```
   WR_CHANGE = WR - WR_prev
   WR_CHANGE_RATE = WR_CHANGE / |WR_prev| × 100
   ```

4. **信号生成逻辑**:
   ```
   买入: WR从<-80向上突破且上升
   卖出: WR从>-20向下突破且下降
   ```
