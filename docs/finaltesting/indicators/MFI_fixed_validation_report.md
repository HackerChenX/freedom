## 技术特点

### MFI指标优势
1. **资金流量分析**: 结合价格和成交量分析资金流向
2. **超买超卖识别**: 准确识别市场的超买超卖状态
3. **背离分析**: 发现价格与资金流量的背离信号
4. **趋势确认**: 帮助确认价格趋势的可靠性

### 计算方法
- **基础公式**: 基于典型价格和成交量的资金流量分析
- **周期参数**: 默认14期，可自定义
- **阈值设定**: 超买线80，超卖线20
- **信号线**: 使用移动平均平滑MFI波动

### 应用场景
1. **资金流向分析**: 判断主力资金的进出
2. **超买超卖判断**: 识别市场极端状态
3. **背离识别**: 发现潜在的反转信号
4. **趋势确认**: 验证价格趋势的强度

## 应用指南

### MFI信号解读
- **MFI > 80**: 超买状态，可能回调
- **MFI < 20**: 超卖状态，可能反弹
- **MFI 20-80**: 正常区间，观察趋势
- **MFI背离**: 价格与资金流量不一致，警示信号

### 交易策略
1. **超买超卖交易**: 在极值区域进行反向交易
2. **背离交易**: MFI与价格背离时的反转机会
3. **趋势跟随**: MFI确认趋势时的跟随策略
4. **资金监控**: 监控主力资金的动向

### 风险控制
- **止损设置**: 当MFI反向突破时考虑止损
- **仓位管理**: 根据MFI强度调整仓位大小
- **时间过滤**: 避免在MFI极值时盲目交易
- **组合使用**: 与其他指标组合使用提高准确性

### 参数优化
- **短期分析**: 使用较短周期(7-10期)
- **中期分析**: 使用标准周期(14期)
- **长期分析**: 使用较长周期(20-30期)
