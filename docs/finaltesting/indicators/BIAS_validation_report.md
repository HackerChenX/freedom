## 算法技术细节

### 核心计算公式 ✅
1. **乖离率计算**:
   ```
   BIAS = (收盘价 - N期移动平均) / N期移动平均 × 100%
   ```

2. **多周期乖离率**:
   ```
   BIAS_6 = (收盘价 - MA6) / MA6 × 100%
   BIAS_12 = (收盘价 - MA12) / MA12 × 100%
   BIAS_24 = (收盘价 - MA24) / MA24 × 100%
   ```

3. **乖离率均线**:
   ```
   BIAS_MA = BIAS的移动平均
   ```

- **超买超卖阈值**: 标准的±3%、±6%阈值设置
- **精度保证**: 使用高精度浮点计算确保准确性
