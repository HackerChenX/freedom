## 算法技术细节

### 核心计算公式 ✅
1. **AROON UP计算**:
   ```
   AROON UP = (period - 最高价距今天数) / period * 100
   ```

2. **AROON DOWN计算**:
   ```
   AROON DOWN = (period - 最低价距今天数) / period * 100
   ```

3. **AROON震荡器**:
   ```
   AROON OSC = AROON UP - AROON DOWN
   ```

4. **信号生成逻辑**:
   ```
   买入: AROON UP > 70 & UP > DOWN & UP上升
   卖出: AROON DOWN > 70 & DOWN > UP & DOWN上升
   ```
