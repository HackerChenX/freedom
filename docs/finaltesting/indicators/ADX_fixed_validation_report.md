## 技术特点

### ADX指标优势
1. **趋势强度量化**: 准确量化趋势的强度，不受价格方向影响
2. **多维度分析**: 结合PDI和MDI提供全面的趋势分析
3. **形态识别丰富**: 提供10种不同的趋势形态识别
4. **信号生成完整**: 包含买入、卖出、持有信号

### 计算方法
- **真实波幅 (TR)**: max(high-low, abs(high-close_prev), abs(low-close_prev))
- **方向移动 (DM)**: 计算正负方向移动
- **方向指标 (DI)**: DM的平滑移动平均 / TR的平滑移动平均 * 100
- **ADX**: DX的平滑移动平均

### 应用场景
1. **趋势确认**: 确认当前市场是否存在明确趋势
2. **趋势强度**: 评估趋势的强弱程度
3. **入场时机**: 在强趋势形成时入场
4. **出场信号**: 在趋势减弱时出场

## 应用指南

### 趋势强度判断
- **ADX < 20**: 市场处于盘整状态，趋势不明显
- **ADX 20-40**: 中等趋势强度，可考虑趋势跟随策略
- **ADX > 40**: 强趋势，适合趋势跟随策略
- **ADX > 60**: 极强趋势，但需警惕反转风险

### 方向判断
- **PDI > MDI**: 上升趋势占主导
- **MDI > PDI**: 下降趋势占主导
- **PDI ≈ MDI**: 趋势方向不明确

### 交易信号
- **买入信号**: ADX上升 + PDI > MDI + ADX > 20
- **卖出信号**: ADX上升 + MDI > PDI + ADX > 20
- **观望信号**: ADX < 20 或 ADX下降

### 风险控制
- **止损设置**: 当ADX开始下降时考虑止损
- **仓位管理**: 根据ADX强度调整仓位大小
- **时间过滤**: 避免在ADX极高时(>70)追涨杀跌
