## 🔍 算法实现分析

### Williams %R核心算法
```python
def _calculate_williams_r(self, df: pd.DataFrame, period: int) -> pd.Series:
    # 计算最高价和最低价
    high_max = df['high'].rolling(window=period).max()
    low_min = df['low'].rolling(window=period).min()
    
    # 计算Williams %R
    wr = -100 * (high_max - df['close']) / (high_max - low_min + 1e-10)
    
    return wr
```
