## 算法技术细节

### 核心计算公式 ✅
1. **江恩角度线计算**:
   ```
   angle_up = swing_low + time_index * angle * 0.1
   angle_down = swing_high - time_index * angle * 0.1
   ```

2. **时间周期信号**:
   ```
   关键位置：cycle//4, cycle//2, 3*cycle//4, 0
   接近高点：close >= cycle_high * 0.95
   接近低点：close <= cycle_low * 1.05
   ```

3. **江恩扇形分析**:
   ```
   强势：above_angles >= len(gann_angles) * 0.7
   弱势：below_angles >= len(gann_angles) * 0.7
   ```

4. **九宫格分析**:
   ```
   price_sqrt = sqrt(close)
   near_square = (fractional < 0.1) | (fractional > 0.9)
   重要分数位：1/8, 1/4, 3/8, 1/2, 5/8, 3/4, 7/8
   ```
