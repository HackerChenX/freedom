## 算法技术细节

### 核心计算公式 ✅
1. **江恩角度线计算**:
   ```
   上升角度线 = 起始价格 + (时间差 × 角度比例)
   下降角度线 = 起始价格 - (时间差 × 角度比例)
   ```

2. **角度比例定义**:
   ```
   1x8: 0.125 (每8个时间单位上升/下降1个价格单位)
   1x4: 0.250 (每4个时间单位上升/下降1个价格单位)
   1x3: 0.333 (每3个时间单位上升/下降1个价格单位)
   1x2: 0.500 (每2个时间单位上升/下降1个价格单位)
   1x1: 1.000 (每1个时间单位上升/下降1个价格单位，45度角)
   ```

3. **时间周期分析**:
   ```
   江恩时间周期 = 基于自然数列和几何级数的时间窗口
   ```

4. **信号生成逻辑**:
   ```
   买入: 价格突破上升角度线且角度线向上
   卖出: 价格跌破下降角度线且角度线向下
   ```

### 特殊处理机制 ✅
- **NaN值处理**: 正确处理计算初期的NaN值
- **动态起点**: 基于关键高低点动态计算角度线起点
- **多重角度**: 同时计算多个角度比例的角度线
- **精度保证**: 使用高精度浮点计算确保准确性
