## 算法技术细节

### 核心计算公式 ✅
1. **SAR计算**:
   ```
   SAR(t) = SAR(t-1) + AF * (EP - SAR(t-1))
   其中：AF为加速因子，EP为极值点
   ```

2. **加速因子调整**:
   ```
   AF初始值 = 0.02
   每次新极值出现时，AF += 0.02
   AF最大值 = 0.2
   ```

3. **极值点更新**:
   ```
   上升趋势：EP = max(high)
   下降趋势：EP = min(low)
   ```

4. **趋势转向判断**:
   ```
   价格突破SAR点时发生趋势转向
   ```

- **NaN值处理**: 正确处理计算初期的NaN值
- **趋势初始化**: 正确初始化趋势方向和SAR值
- **加速因子重置**: 趋势转向时重置加速因子
- **精度保证**: 使用高精度浮点计算确保准确性
