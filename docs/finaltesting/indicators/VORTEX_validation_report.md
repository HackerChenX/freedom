## 算法技术细节

### 核心计算公式 ✅
1. **真实范围（TR）计算**:
   ```
   TR = max(high - low, |high - prev_close|, |low - prev_close|)
   ```

2. **涡流运动计算**:
   ```
   VM+ = |high - prev_low|
   VM- = |low - prev_high|
   ```

3. **涡流指标计算**:
   ```
   VI+ = sum(VM+, period) / sum(TR, period)
   VI- = sum(VM-, period) / sum(TR, period)
   ```

4. **涡流分析指标**:
   ```
   VORTEX_DIFF = VI+ - VI-
   VORTEX_RATIO = VI+ / VI-
   VORTEX_STRENGTH = |VI+ - VI-|
   ```
