## 算法技术细节

### 核心计算公式 ✅
1. **资金流乘数 (MFM)**:
   ```
   MFM = ((Close - Low) - (High - Close)) / (High - Low)
   ```

2. **资金流量 (MFV)**:
   ```
   MFV = MFM × Volume
   ```

3. **累积/派发线 (AD Line)**:
   ```
   AD = Σ(MFV) = 前期AD + 当期MFV
   ```

4. **佳庆振荡器 (CHAIKIN)**:
   ```
   CHAIKIN = EMA(AD, fast_period) - EMA(AD, slow_period)
   ```

### 特殊处理机制 ✅
- **除零保护**: 当High=Low时，使用np.nan避免除零错误
- **NaN值填充**: 使用fillna(0)处理NaN值
- **EMA计算**: 使用pandas ewm()方法进行高效EMA计算
- **累积计算**: 使用cumsum()进行高效累积计算
