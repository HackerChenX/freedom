## 算法技术细节

### 核心计算公式 ✅
1. **向上跳空识别**:
   ```
   up_gap = (low[i] > high[i-1]) & (high[i-1].notna())
   ```

2. **向下跳空识别**:
   ```
   down_gap = (high[i] < low[i-1]) & (low[i-1].notna())
   ```

3. **顶部岛形反转**:
   ```
   向上跳空后在5天内出现向下跳空
   ```

4. **底部岛形反转**:
   ```
   向下跳空后在5天内出现向上跳空
   ```

5. **跳空幅度计算**:
   ```
   gap_size = (gap_price - reference_price) / reference_price
   ```
