## 算法技术细节

### 核心计算公式 ✅
1. **转换线（Tenkan-sen）**:
   ```
   转换线 = (9日最高价 + 9日最低价) / 2
   ```

2. **基准线（Kijun-sen）**:
   ```
   基准线 = (26日最高价 + 26日最低价) / 2
   ```

3. **先行带A（Senkou Span A）**:
   ```
   先行带A = (转换线 + 基准线) / 2，向前移动26日
   ```

4. **先行带B（Senkou Span B）**:
   ```
   先行带B = (52日最高价 + 52日最低价) / 2，向前移动26日
   ```

5. **滞后线（Chikou Span）**:
   ```
   滞后线 = 收盘价，向后移动26日
   ```

### 特殊处理机制 ✅
- **NaN值处理**: 正确处理计算初期的NaN值
- **时间移位**: 正确处理先行带和滞后线的时间移位
- **云图计算**: 动态计算云图上沿、下沿和厚度
- **精度保证**: 使用高精度浮点计算确保准确性
