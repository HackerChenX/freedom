## 🔍 算法实现分析

### KDJ核心算法
```python
def _calculate_kdj(self, data: pd.DataFrame) -> pd.DataFrame:
    # 计算RSV (Raw Stochastic Value)
    high_max = data['high'].rolling(window=self.n).max()
    low_min = data['low'].rolling(window=self.n).min()
    rsv = 100 * (data['close'] - low_min) / (high_max - low_min + 1e-10)
    
    # 计算K值 (平滑RSV)
    k = rsv.ewm(alpha=1/self.m1).mean()
    
    # 计算D值 (平滑K值)
    d = k.ewm(alpha=1/self.m2).mean()
    
    # 计算J值 (加速线)
    j = 3 * k - 2 * d
    
    return k, d, j
```
