## 算法技术细节

### 核心计算公式 ✅
1. **量比计算**:
   ```
   VR = Σ(上涨成交量) / Σ(下跌成交量) over N periods
   ```

2. **量比移动平均**:
   ```
   VR_MA = MA(VR, period)
   ```

3. **量比变化**:
   ```
   VR_CHANGE = (VR - VR_prev) / VR_prev × 100%
   ```
