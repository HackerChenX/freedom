## 算法技术细节

### 核心计算公式 ✅
1. **三星形态识别**:
   ```
   三白兵 = 连续三根阳线且每根收于接近最高点
   三黑鸦 = 连续三根阴线且每根收于接近最低点
   ```

2. **复合形态识别**:
   ```
   上升三法 = 长阳线 + 三根小阴线 + 长阳线
   下降三法 = 长阴线 + 三根小阳线 + 长阴线
   ```

3. **复杂形态识别**:
   ```
   头肩顶 = 左肩 + 头部 + 右肩 (头部最高)
   双顶 = 两个相近的高点 + 中间的低点
   ```
