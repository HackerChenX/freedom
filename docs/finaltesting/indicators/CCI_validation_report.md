## 算法技术细节

### 核心计算公式 ✅
1. **典型价格计算**:
   ```
   TP = (最高价 + 最低价 + 收盘价) / 3
   ```

2. **移动平均计算**:
   ```
   MA = TP的N期移动平均
   ```

3. **平均偏差计算**:
   ```
   MD = |TP - MA|的N期移动平均
   ```

4. **CCI计算**:
   ```
   CCI = (TP - MA) / (0.015 × MD)
   ```
