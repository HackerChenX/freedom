# 技术指标形态管理规范

## 📋 问题背景

通过系统性分析发现，当前项目中存在严重的形态命名不一致问题：

- **总形态数量**: 1190个
- **规范形态**: 13个 (1.1%)
- **非规范形态**: 465个 (39.1%)
- **未知形态**: 712个 (59.8%)
- **一致性率**: 仅1.1% ❌

## 🎯 解决方案：统一形态管理规范

### 1. 核心原则

#### 1.1 单一数据源原则
- **每个形态只在一个地方定义**
- 所有组件从统一形态注册表获取形态信息
- 禁止在多个文件中重复定义相同形态

#### 1.2 规范命名原则
- 使用统一的形态命名规范
- 形态名称必须具有明确的技术含义
- 避免模糊或重复的命名

#### 1.3 分层管理原则
- **通用形态**: 适用于多个指标的标准形态
- **指标特定形态**: 仅适用于特定指标的专有形态
- **别名映射**: 处理历史遗留命名问题

### 2. 统一形态注册表架构

#### 2.1 核心组件
```python
# indicators/pattern/unified_pattern_registry.py
class UnifiedPatternRegistry:
    """统一形态注册表 - 系统唯一的形态定义源"""
    
    def __init__(self):
        self._patterns: Dict[str, Dict[str, Any]] = {}
        self._indicator_patterns: Dict[str, Set[str]] = {}
        self._pattern_aliases: Dict[str, str] = {}
```

#### 2.2 标准形态分类

##### 2.2.1 交叉类形态 (CROSS)
- `GOLDEN_CROSS`: 金叉 - 快线上穿慢线
- `DEATH_CROSS`: 死叉 - 快线下穿慢线

##### 2.2.2 背离类形态 (DIVERGENCE)
- `BULLISH_DIVERGENCE`: 牛市背离 - 价格创新低，指标不创新低
- `BEARISH_DIVERGENCE`: 熊市背离 - 价格创新高，指标不创新高

##### 2.2.3 突破类形态 (BREAKOUT)
- `UPPER_BREAKOUT`: 上轨突破 - 价格突破上轨阻力
- `LOWER_BREAKOUT`: 下轨突破 - 价格跌破下轨支撑

##### 2.2.4 振荡器形态 (OSCILLATOR)
- `OVERBOUGHT`: 超买 - 指标进入超买区域
- `OVERSOLD`: 超卖 - 指标进入超卖区域

```python
# 从统一注册表获取形态映射
def get_pattern_mapping_for_data_generator(self) -> Dict[str, str]:
    """获取数据生成器使用的形态映射"""
    mapping = {}
    for pattern_id, pattern_info in self._patterns.items():
        if pattern_info['category'] == PatternCategory.CROSS.value:
            if pattern_info['pattern_type'] == PatternType.BULLISH.value:
                mapping[pattern_id] = "GOLDEN_CROSS"
            elif pattern_info['pattern_type'] == PatternType.BEARISH.value:
                mapping[pattern_id] = "DEATH_CROSS"
        # ... 其他映射逻辑
    return mapping
```
