## ⚠️ 常见问题快速解决

### 问题1: 计算结果差异大
```python
# 检查EMA方法
methods = ['standard', 'sma_init', 'wilder']
for method in methods:
    result = calculate_with_method(data, method)
    print(f"{method}: {result}")
```

### 问题2: 日期不匹配
```python
# 使用精确日期匹配
target_date = pd.to_datetime('2025-05-12').date()
target_rows = df[df['date'].dt.date == target_date]
```

### 问题3: 数据长度不足
```python
# 检查数据要求
min_days = INDICATOR_REQUIREMENTS[indicator_type]['min_days']
if len(df) < min_days:
    df = get_more_data(stock_code, days=min_days*2)
```

## 📊 质量标准

### 准确率要求
- **核心指标** (MACD, RSI, BOLL): ≥99.5%
- **重要指标** (MA, EMA, KDJ): ≥99.0%
- **一般指标**: ≥98.0%

### 性能要求
- **单股票计算时间**: <1秒
- **批量处理**: <30秒/100股票
- **内存使用**: <500MB

### 稳定性要求
- **计算一致性**: 100%（多次计算相同结果）
- **数据质量率**: ≥95%
- **异常处理覆盖率**: 100%

## 🔄 标准修复流程

### 1. 快速诊断 (15分钟)
```bash

```

```bash
python validation/deep_analysis.py --indicator [指标名] --comprehensive
```

### 3. 修复实施 (60分钟)
```bash

```

### 4. 验证测试 (30分钟)
```bash
python validation/comprehensive_test.py --indicator [指标名] --verify-fix
```
