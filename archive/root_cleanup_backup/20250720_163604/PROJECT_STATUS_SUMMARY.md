## 💡 使用建议

### 1. 快速开始
```python
# 1. 导入核心组件
from strategy.strategy_executor import StrategyExecutor
from analysis.buypoints.buypoint_strategy_adapter import get_buypoint_strategy_adapter

# 2. 创建执行器和适配器
executor = StrategyExecutor()
adapter = get_buypoint_strategy_adapter()

# 3. 执行选股策略
results = executor.execute_strategy("momentum_strategy")
```

### 2. 买点分析集成
```python
# 1. 买点分析
buypoint_results = analyzer.analyze_batch(stock_codes)

# 2. 格式转换

filtered_results = strategy_results[strategy_results['score'] >= 70]
```
