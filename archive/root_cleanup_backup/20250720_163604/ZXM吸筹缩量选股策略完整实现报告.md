## 技术架构

### 1. 技术指标选择

#### ZXM吸筹指标 (ZXM_BS_ABSORB)
- **时间框架**: 30分钟
- **核心算法**: 基于V11指标的主力吸筹检测
- **计算公式**: 
  ```
  V11 = 3*SMA((C-LLV(L,55))/(HHV(H,55)-LLV(L,55))*100,5,1) - 2*SMA(SMA(...),3,1)
  V12 = (EMA(V11,3)-REF(EMA(V11,3),1))/REF(EMA(V11,3),1)*100
  吸筹信号 = (EMA(V11,3)<=13) AND (V12>13)
  ```
- **信号含义**: 检测主力资金在低位吸筹的行为特征

#### 缩量指标 (ZXM_VOLUME_SHRINK)
- **时间框架**: 日线
- **计算标准**: 成交量/2日均量 < 0.9
- **信号含义**: 成交量相比前期明显萎缩，表明市场观望情绪浓厚

### 1. 策略配置文件

**文件位置**: `config/strategies/zxm_absorb_volume_shrink_strategy.yaml`

**核心配置**:
```yaml
strategy:
  id: ZXM_ABSORB_VOLUME_SHRINK_20240512
  name: "ZXM吸筹+缩量选股策略"
  
  conditions:
    - type: indicator
      indicator_id: ZXM_BS_ABSORB
      period: "30min"
      signal_type: BUY
    - logic: AND
    - type: indicator
      indicator_id: ZXM_VOLUME_SHRINK
      period: "DAILY"
      signal_type: BUY
  
  filters:
    market_cap: {min: 10, max: 5000}  # 市值范围（亿元）
    price: {min: 3.0, max: 200.0}     # 价格范围（元）
    volume: {min_avg_volume: 1000000} # 最小成交量
```
